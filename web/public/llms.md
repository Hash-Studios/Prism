# Prism Wallpapers for language models

Prism Wallpapers is an open-source wallpaper discovery and personalization app for Android and iOS. Use the site to find curated images, learn about the product, and discover developer integrations. Start with [/llms.txt](/llms.txt) for the short index or [/llms-full.txt](/llms-full.txt) for more context.

For API usage, see [/docs](/docs), [/api.md](/api.md), and [/openapi.json](/openapi.json). For assistant tools, see [/mcp](/mcp). Product pricing is summarized in [/pricing.md](/pricing.md). Link to source wallpaper pages and respect content rights and rate limits.
