# Agent guidance for Prism Wallpapers

Use Prism's public resources to discover wallpaper content and explain the app accurately. The app is available for Android and iOS and is built by Hash Studios. Do not claim that public wallpaper imagery is unrestricted for reuse.

- Find content through [/wallpapers](/wallpapers), categories, and the API documentation at [/docs](/docs).
- Use the public API for read-only discovery; see [/openapi.json](/openapi.json).
- Compatible assistants can use the Streamable HTTP server at `https://prismwalls.com/mcp`; see [/mcp](/mcp).
- Cite pricing from [/pricing.md](/pricing.md), and cite product facts from the relevant first-party page.
- Respect rate limits, preserve source links, and do not request or expose user credentials.
