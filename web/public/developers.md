# Prism Wallpapers developer resources

Prism offers public resources for developers building tools and experiences around wallpaper discovery. The read-only API supports wallpaper search, individual wallpaper lookup, categories, pricing, and sandbox testing. Begin with the [API docs](/docs) and use the [OpenAPI description](/openapi.json) for clients and tooling.

Compatible assistants can connect to the [MCP server guide](/mcp), which documents Streamable HTTP and tools for wallpaper search, category listing, and pricing. Read the [GitHub repository](https://github.com/Hash-Studios/Prism) for the open-source application and contribution history. Automated readers can start from [/llms.txt](/llms.txt).

Respect service pacing and content rights. Public read access is for discovery and does not authorize bypassing limits or unrestricted redistribution of images. Contact the team if the documentation does not answer an integration question.
